# 天文信息查询工具

一个用于 AstrBot 的天文信息查询插件，支持月相、日月与八大行星升落、深空天体资料与升落查询、今夜目标推荐、三级曙暮光、当日综合天文信息，以及晴天钟天文预报与观星评分。既可以使用聊天命令，也可以通过 AstrBot 的大语言模型工具调用。

- 插件名称：`astrbot_plugin_astronomy`
- 当前版本：`v0.0.7`
- 作者：数星星的小白兔
- 项目地址：https://github.com/StarRabbit2024/astrbot_plugin_astronomy

## 功能一览

- **月相查询**：计算指定时刻的近似月龄、月面照明率和八相名称。
- **指定日期升落查询**：查询太阳、月球、八大行星或深空天体在某个北京时间日期内的升起、中天和落下时间，以及中天高度。
- **当前状态查询**：查询天体当前高度、是否位于地平线上，以及后续升落和中天信息。
- **深空天体资料查询**：按中文名、M/NGC/IC 编号或英文别名查询星等、类型、星座、视大小和当日升落信息。
- **今夜目标推荐**：从星等较亮且今夜上中天的目标中，按星等、中天高度、月距和月面照明率进行启发式排序。
- **曙暮光查询**：分别计算民用、航海和天文晨光始、昏影终，并处理高纬度地区全日无跨越事件的情况。
- **今日观星汇总**：汇总当日太阳、月球、七大行星、月相和曙暮光信息。
- **晴天钟预报**：返回未来 72 小时晴天钟图表，并对未来约 48 小时内尚未过去的凌晨、夜晚时段给出观星评分。
- **大模型天文预报**：向大模型提供未来 3 天夜间逐时段的云量、视宁度、透明度、湿度、降水和气温预报；缺测字段显示为“无数据”。

## 安装

### 通过仓库地址安装

在 AstrBot 的插件管理功能中选择从仓库安装，填写：

```text
https://github.com/StarRabbit2024/astrbot_plugin_astronomy
```

### 手动安装

将本插件目录放入 AstrBot 的插件目录，然后重启 AstrBot 或在插件管理中重新加载插件。

插件仅使用 Python 标准库和 AstrBot 提供的插件接口，无需额外安装第三方 Python 包。月相、天体位置和深空天体计算在本地完成；使用晴天钟功能时，需要能够访问 `www.7timer.info`。

安装或升级时请确保 `DSO_database.json` 与 `skydb.py` 一同保留在插件目录中，否则插件会在导入数据库时失败。

## 配置

在 AstrBot 插件配置中设置观测地点：

| 配置项 | 含义 | 默认值 |
| --- | --- | ---: |
| `latitude` | 观测点纬度，北纬为正、南纬为负 | `31.94` |
| `longitude` | 观测点经度，东经为正、西经为负 | `118.79` |

经纬度使用十进制度数。例如，北纬 31.94°、东经 118.79° 分别填写 `31.94` 和 `118.79`。

观测地点同时用于本地天体计算、今夜目标推荐和晴天钟预报。日期和时刻按**北京时间（UTC+8）**设计；使用“当前时刻”或“今天”等默认输入时，还应确保 AstrBot 所在设备的系统时间和时区设置正确。

## 命令使用

| 命令 | 用途 | 参数 |
| --- | --- | --- |
| `/月相 [时间]` | 查询月相 | 时间格式为 `YYYY-MM-DD HH:MM`；省略时查询当前时刻 |
| `/当日升落 [日期] [天体]` | 查询指定日期的升落与中天 | 日期格式为 `YYYY-MM-DD`；日期和天体均可省略，默认查询当日太阳 |
| `/天体状态 [天体]` | 查询天体当前状态和后续事件 | 省略天体时默认查询太阳 |
| `/当日蒙影 [日期]` | 查询三级曙暮光 | 日期格式为 `YYYY-MM-DD`；省略时查询当日 |
| `/今日观星` | 查询当日综合天文信息 | 无参数 |
| `/晴天钟` | 查询晴天钟图表和夜间观星评分 | 无参数，使用配置的观测地点 |
| `/深空天体 <名称>` | 查询深空天体资料和当日升落 | 必须提供中文名、编号或英文别名 |
| `/今夜目标` | 查询今夜推荐深空目标 Top 5 | 无参数 |

### 示例

```text
/月相
/月相 2026-11-09 21:00
/当日升落 2026-11-09 SUN
/当日升落 2026-11-09 M31
/当日升落 2026-11-09 NGC 224
/天体状态 MOON
/天体状态 Andromeda Galaxy
/当日蒙影 2026-11-09
/今日观星
/晴天钟
/深空天体 M31
/深空天体 NGC 224
/深空天体 玫瑰星云
/今夜目标
```

### 太阳、月球与行星名称

| 名称 | 天体 |
| --- | --- |
| `SUN` | 太阳 |
| `MOON` | 月球 |
| `MERCURY` | 水星 |
| `VENUS` | 金星 |
| `MARS` | 火星 |
| `JUPITER` | 木星 |
| `SATURN` | 土星 |
| `URANUS` | 天王星 |
| `NEPTUNE` | 海王星 |

日月、行星和深空天体查询统一忽略英文名称的大小写，以及名称中的普通空格和全角空格。例如，`NGC 224` 与 `NGC224` 均可使用；带空格的英文别名也可以用于升落和状态查询。

## 深空天体数据库

数据库文件为 `DSO_database.json`，目前包含 **157 个条目**：

- 完整的 110 个梅西耶天体条目。
- 47 个其他常见星云、星团、星系或星群条目。

`/深空天体` 可返回以下字段：

- 中文主名、天体类型和所属星座。
- V 星等；无数据时显示“无数据”。
- 视大小；无数据时显示“无数据”。
- 当日升起、上中天和落下时间，以及中天高度。

数据库记录的坐标历元为 **J2000**。计算升落时，插件先按低精度速率公式将坐标修正到查询时刻，再调用与日月、行星相同的升落引擎。数据库文件记录的主要来源为 OpenNGC，并使用 Yale Bright Star Catalog 进行部分交叉核对。

`v0.0.7` 配套的数据库版本为 `1.1`，统一了编号空白、星座中文字段和缺失视大小的 `null` 表示，并清理了部分容易混淆的别名与备注。所有名称和规范化别名均保持唯一。

星等通常表示目标的**总星等**，不代表面亮度。对于大面积星系和星云，即使总星等较亮，实际目视或拍摄难度也可能较高。

## 今夜目标推荐

`/今夜目标` 的筛选与排序逻辑为：

1. 仅保留有星等数据且星等不大于 8 等的目标。
2. 仅保留上中天时刻位于北京时间 21:00 至次日 03:00 的目标。
3. 将星等分和中天高度分各占 50% 合成基础分。
4. 根据目标上中天时的月距和月面照明率进行避月惩罚：月距小于 10° 时最强惩罚为乘 `0.2`，10°～30° 时最强惩罚为乘 `0.7`。
5. 惩罚强度随照明率线性变化：满月附近保留完整惩罚，新月附近不施加月距惩罚。
6. 排序后返回前 5 个目标；大模型工具支持指定返回数量，设计范围为 3～10。

避月评分以目标中天时的月距和照明率为依据，不单独使用月球高度角。该榜单是本地启发式推荐，不是实际可见性的保证，也未纳入曙暮光、天气、光污染、目标面亮度和观测设备等因素。

## 晴天钟与观星评分

`/晴天钟` 会依次返回：

1. 今日凌晨、今日夜晚、明日凌晨和明日夜晚中，尚未过去且有有效预报数据的时段评分。
2. 当前观测地点的未来 72 小时晴天钟图表。

评分范围为 **0～100 分**，等级划分如下：

| 分数 | 等级 |
| --- | --- |
| 90～100 | 极佳 |
| 70～89 | 良好 |
| 50～69 | 一般 |
| 30～49 | 较差 |
| 0～29 | 极差 |

评分是插件根据晴天钟预报和本地月相、月球位置计算的**自定义参考指标**，并非晴天钟官方评分。云量作为主要限制因子，存在降水时该因子按零分处理；其余部分综合月光、透明度和视宁度，权重依次为 `5:4:3`。

同一观测地点的晴天钟数据会缓存约 30 分钟，因此短时间内的重复查询可能使用缓存结果。网络请求失败或接口返回无效数据时，插件会提示预报获取失败；大模型详细预报中的缺测字段会显示为“无数据”。

## 输出说明与精度

- 日出、日落采用约 `-0.833°` 的高度阈值；月球采用约 `0.125°`；行星和深空天体采用约 `-0.567°`。这些阈值用于近似计入视半径、大气折射或月球视差等影响。
- “中天”指天体经过当地子午圈的上中天；“中天高度”为计算得到的地平高度，不是方位角。
- 在高纬度地区，天体可能整日不升、不落，某个自然日内也可能没有完整的升起、中天和落下事件；曙暮光输出会区分完整事件、仅有单个事件和全天无跨越事件。
- `/今日观星` 中的月相按当日北京时间 12:00 计算，其余项目按当日日期计算；该命令本身不获取天气预报。
- `/晴天钟` 使用的是预报而非实测天气，观星评分不能替代临行前对实时天气与当地环境的确认。

本项目的月相和天体位置采用轻量级本地近似计算，不依赖在线星历服务：

- 太阳位置使用低精度解析公式。
- 月球位置使用截断的周期项级数。
- 行星位置由开普勒轨道根数和开普勒方程迭代求得。
- 月龄按平均朔望月估算，照明率由月相角的余弦近似得到。
- 深空天体使用静态星表坐标和近似岁差修正。
- 升落事件通过球面天文公式和迭代修正计算。

结果适合日常科普、聊天查询和一般观测参考，不属于高精度星历。模型未完整处理光行时、周年光行差、章动、真实大气折射变化及观测点海拔等影响；月龄和照明率也不等同于精密星历结果。请勿将其用于精密测量、导航或其他对时间和位置精度要求较高的场景。

```text
astrbot_plugin_astronomy/
├── main.py            # AstrBot 命令与大语言模型工具入口
├── moon_phase.py      # 月相近似计算
├── riseset.py         # 天体位置、名称规范化与升落计算
├── almanac.py         # 曙暮光与当日信息汇总

├── DSO_database.json  # 深空天体数据库
├── _conf_schema.json  # 观测地点配置

```
